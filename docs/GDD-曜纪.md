### D10 附：轨道寿命 Monte-Carlo 实测（60 种子，工具：`astro.tools.MonteCarloTool`）

| 构型 | 中位寿命 | 结论 |
|---|---|---|
| 8 字形周期解 + 1% 微扰 | 3.3 年（60/60 坠焚） | 每周期必近距交会，弃用 |
| 层级圆外轨 a=18 | >4775 年全存活 | 太稳无戏剧性，弃用 |
| **层级偏心外轨 a=12, e=0.5 + 2% 微扰（采用）** | P25=181 年 / 中位 2306 年 / 47% 长寿 | 短局紧张、长局"黄金纪元"，配合经营失败死因形成完整难度谱 |

设计注记：轨道力学只提供**纪元日程表**；文明主要死因应来自经营失败（乱曜/烈曜
下的存粮与晶眠决策），长寿种子 = D3 的"黄金纪元"jackpot（单局可达结局）。

## 1. 一句话概念

> 你是三星混沌行星的文明管理者：在真实三体引力模拟驱动的随机灾变下，抓住
> 序曜期的窗口发展工业与科学，用晶眠机制保存火种，跨轮回积累知识——最终发现
> 三体问题在数学上不可解，唯一的出路是把整个文明改造成星际舰队，走向宇宙。

**主题机制化**：Roguelike 的轮回 = 文明的纪元更替；"不可解"不是叙事台词，
而是玩家亲手验证的数学事实；"失败即胜利"（输掉数学、赢得生存）构成终局反转。

## 2. 双层世界架构（D1 的技术设计）

### 2.1 两层模拟

| 层 | 内容 | 时间特性 |
|---|---|---|
| **星系层** | 三颗恒星的 N 体引力积分（RK4/Leapfrog，固定步长），派生：纪元分类、气候、昼夜、灾变事件 | 永远运行（含暂停）；时间倍率可调（1x/3x/观测加速） |
| **地表层** | 建造网格、资源、人口智能体、建筑、生产链 | **宇宙视角时继续运行**（D5）；市民模拟自动降级为统计抽象（D6 双层 LOD） |

**一致性铁律**：天空中的太阳位置、纪元判定、灾变全部从星系层同一份模拟状态
派生——宇宙视角看到的三星之舞，就是地表经历的天气。这是"真模拟"卖点的根基。

### 2.2 无缝缩放的实现策略（伪无缝，三段式交叉淡化）

行星半径 ~10^3 km 与星系尺度 ~10^8 km 相差 5 个数量级，真单尺度渲染会撞
float32 精度墙（floating origin 问题）。业界成熟解法（Empire Earth / Spore /
No Man's Sky 均为变体）：

```
[地表场景] --拉远--> [星球代理层] --拉远--> [星系轨道视图]
  局部坐标            行星球体代理             示意图式轨道渲染
  45°透视相机         (纹理球+大气辉光)        (真实模拟数据画轨道线)
        \______ 交叉淡化(HDR后处理混合) ______/
```

- 过渡编排：相机沿轨道拉升 + 场景交叉淡化 + 星空背景保持一致 + 太阳位置连续
  （来自同一份模拟数据）→ 感知上"一镜到底"
- mog-engine 落点：两个 Scene 实例 + PostProcessor 增加双场景混合 pass；
  HDR/泛光已就位（恒星辉光免费）；轨道线渲染 = LINE_STRIP 新管线（小）
- 宇宙视角的"壮观"预算：轨道残影（历史轨迹渐隐）、三星引力场可视化（可选
  等高线/流场）、纪元时间轴 UI

### 2.3 主玩法相机（地表层）

- 45° 俯视透视相机（轻微透视而非纯正交，保留 3D 立体感与缩放景深）
- WASD 平移 + 滚轮缩放（限定高度区间）+ 中键旋转（可选）
- 建造网格：32×32 起步（约 64m×64m 活动区），后续纪元可解锁扩张

## 3. 纪元模拟（随机性毁灭的设计）

### 3.1 纪元分类（从三星相对位置实时判定）

| 纪元 | 天文条件 | 地表效果 |
|---|---|---|
| 序曜期（稳定） | 主星稳定出没了带 | 正常生产；可预测 |
| 乱曜期（混沌） | 多星交织/远离 | 温度异常，生产衰减 |
| 烈曜（烈日） | 近距离双星/三星凌空 | 高温焚城；未晶眠人口死亡 |
| 寒曜（极寒） | 三星皆远 | 冻结；能源消耗激增 |
| 蚀曜（三日连珠） | 三星成线 | 罕见奇观 + 全局危机事件 |
| 飞星期 | 恒星近距掠过 | 预警窗口短、烈度高的突发灾变 |

### 3.2 可预测性三段设计（核心技能曲线）

- **短期（分钟级）**：天文台观测 → 精确预报（可玩的信息管理）
- **中期（纪元级）**：统计规律 → 概率预报（科学投资回报）
- **长期**：数学上不可预测 → 混沌（主题的机制化表达；玩家亲手触摸"不可解"）
- 预报 UI = 「历法面板」：时间轴 + 置信区间条带，精度随天文台等级提升

### 3.3 毁灭与缓冲

- 人口死亡 ≠ 立即失败：**晶眠库**中的人口可复活（原著"脱水"的机制化）
- 失败判定：活动人口 + 晶眠人口 = 0 → 文明毁灭 → 结算 → 知识传承
- 难度旋钮：晶眠损耗率、灾变预警时长、复活资源成本

## 4. 建造与生产

- **生产链**：矿石 → 金属 → 电路 → {望远镜(预测) | 计算机(研究) | 晶眠舱(生存) | 舰船部件(终局)}
- **人口双重性**：劳动力（生产/研究）⇄ 火种（晶眠保存）；乱曜期前的"全民晶眠"
  决策是标志性抉择时刻
- **奇观建筑**（叙事+功能合一）：巨型单摆（历法校准/预测加成）、人列计算机
  （大规模并行研究事件）、引力波天线（终局通信）、星港（结局建筑）
- 建筑放置：网格吸附 + 地形限制 + 邻接加成（相邻协同的摆放策略）

## 5. 知识与成就（跨局 Meta）

### 5.1 三层知识体系

| 层 | 载体 | 死亡时 |
|---|---|---|
| 局内科技树 | 研究点 → 建筑/效率/预测 | 全失 |
| 文明记忆库 | 毁灭结算按成就折算「传承点」→ 永久公式/起始加成/新基因 | 保留 |
| **启示知识** | 叙事性发现（如《不可解性证明》）→ **改变规则本身** | 永久保留 |

启示知识是质的阶梯：解锁新机制（如晶眠科技）、新纪元类型认知、新结局分支。

### 5.2 里程碑三幕（跨局主线）

1. **数学之幕**：学会生存与预测（新手期数个轮回）
2. **绝望之幕**：集齐启示→不可解性证明（剧情转折点，资源目标强制转向）
3. **远航之幕**：星港+舰队建造 → **起航 = 真结局（宇宙级旅者）**

隐藏结局：伪解（数值过拟合的自欺）、静默广播（黑暗森林 homage）、单舰逃亡
（道德抉择：带走谁？——成就线）。

### 5.3 成就四轴

科学（首次成功预报/证明不可解）、生存（连续渡过 N 个乱曜期）、
建造（奇观全收集）、哲学（每个终局抉择一次）。

## 6. 单局结构（模拟驱动，非人为定时）

**设计公理（D3 核心）**：局长与结局由三体模拟的混沌统计自然涌现，**不做人为的
"到点强制灾难"**。30-60 分钟只是混沌轨道下的典型值；理论上存在极低概率的
"黄金纪元"——三星意外进入超长稳定构型，玩家得以**一局之内从零走到舰队起航**。

支撑公理的两条铁律：

1. **单局可达**：所有内容（含《不可解性证明》、星港、起航结局）在单局内都有
   获取路径（深研究投资 + 奇观链条）。跨局传承只提供**便利与加速**
   （起始科技/传承公式），**绝不设内容门槛**——否则"一次成功"在结构上不可能，
   黄金局就失去了意义（Hades/Dead Cells 哲学：meta 是捷径，不是钥匙）
2. **稀有即史诗**：黄金纪元出现时，系统识别并授予专属成就（"天佑曜纪"级），
   结算画面记录该局的轨道参数——**可复现可分享的低概率奇迹**，Roguelike
   社区传播的天然素材

典型节奏（混沌统计下的中位数体验）：

```
0-5min   开局：小型序曜期窗口，教学性采集+首批建筑
5-20min  第一扩张期：人口增长、生产链铺开、首座天文台
20-35min 危机升级：乱曜期变长变烈、晶眠决策、可能的首次毁灭边缘
35-50min 后期：奇观建筑、启示知识触发点、舰队部件（若研究路线到达）
50-60min 终局：起航判定 / 毁灭结算 → 传承点结算画面 → 知识树 UI
（黄金纪元分支：序曜期持续异常之久 → 一路平推至起航，一局封神）
```

失败即进度：毁灭结算展示"本次文明留下了什么"，Roguelike 的正反馈闭环。

垂直切片定义（C1-C3 完成时）：
> 从宇宙视角看三星混沌之舞 → 无缝推近到行星 → 放两个采集者和一座晶眠舱 →
> 烈曜来临 → 手动晶眠一半人口 → 另一半死亡 → 纪元结束毁灭结算 →
> 重开时传承点 +1。**这一小段就是游戏灵魂的最小完整体。**
